# 🏨 Hotel Management System

A full-stack Hotel Management System developed to simplify hotel operations, room management, and reservations.

## 🚀 Technologies Used

- **Backend:** Java 17, Spring Boot, Spring Data JPA
- **Frontend:** React.js, Vite, Axios
- **Database:** MySQL
- **Tools:** Eclipse, VS Code, Postman, Git & GitHub

## ✨ Features

- Room management (Add, View, Update, Delete)
- Room availability and status management
- REST API integration
- React-based user interface
- MySQL database integration

## ⚙️ How to Run the Project

### Backend

1. Open the backend project in Eclipse.
2. Configure MySQL in `application.properties`.
3. Create the database:

```sql
CREATE DATABASE hotel_management;
```

4. Run `HotelManagement2Application.java`.
5. Backend URL: `http://localhost:8080`

### Frontend

1. Open the frontend folder in VS Code.
2. Install dependencies:

```bash
npm install
```

3. Start React:

```bash
npm run dev
```

4. Open the localhost URL displayed in the terminal.
